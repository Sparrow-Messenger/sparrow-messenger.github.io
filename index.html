02 / Federation

Host a Community Node

Every independent relay and mailbox operator strengthens circuit diversity. Deploy the unified Ktor + Caddy Docker stack on any Linux, macOS, or Windows host with ports 80 and 443 open.

Clone the Server Bundle

Terminal 
git clone https://github.com
cd Sparrow/server

Configure Your Node

server/.env

.env 
SPARROW_DOMAIN=node.example.org
SPARROW_OPERATOR_NAME="My Community Node"
SPARROW_CONTROL_PLANES=https://sparrow-messenger.org

Copy .env.example to .env and set your public domain so Caddy can automatically provision TLS certificates.

Build & Launch

Terminal 
docker compose up -d --build

Starts the Ktor relay/mailbox service alongside Caddy reverse proxy in the background.

Verify Your Endpoint

Terminal 
curl -I https://example.org

Returns HTTP/2 200 with your live gateway, federation, and mailbox status page. Read full hosting docs →
