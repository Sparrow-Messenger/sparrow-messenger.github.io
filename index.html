03 / Contribute

Contribute to Sparrow

Sparrow is built in the open, and its future depends on people taking part. You don’t need to be a developer to help: you can run a server, improve the app, test new changes, or help cover project costs. Choose what fits your skills and time.

What your contribution makes possible

More independently run servers give people more choices for message delivery. Code contributions and testing help improve the app, while financial support helps pay for test servers, development, and an independent security review. Every kind of help supports a more resilient, community-run messenger.

Help run a Sparrow server

Running a server gives the network another independently operated place to pass messages. It takes a computer that can stay online and some comfort following setup instructions. It’s optional: most people can just use Sparrow on Android. The steps below walk through setup.

Get the server files

Commands 
git clone https://github.com
cd Sparrow/server

Set up your server

server/.env

.env 
SPARROW_DOMAIN=node.example.org
SPARROW_OPERATOR_NAME="My Community Node"
SPARROW_CONTROL_PLANES=https://sparrow-messenger.org

Copy .env.example to .env and enter the web address for your server. The secure connection will be set up automatically.

Start the server

Commands 
docker compose up -d --build

This starts the programs that deliver messages and keep the connection secure.

Check that it’s working

Commands 
curl -I https://example.org

If everything is working, you’ll see HTTP/2 200. That means your server is responding. Read the server setup guide →

Code contributions

Sparrow’s app and server code are public on GitHub. Developers can learn how the project works, fix problems, or suggest improvements. Browse the repository and open issues to see what the project is working on. If you’re unsure where to start, ask a question before tackling a larger change.
